# lite-for-jdbc

lite-for-jdbc is at the end of its life. 

Lite-for-JDBC was created to fill a void that existed in 2022. As of 2025, JDBI
now seems to perform all the tasks that lite-for-jdbc does with a much larger user and
contributor base. So it has become of opinion of the creators and maintainors of lite-for-jdbc
that a migration to JDBI is the most practical path forward. 

[A migration](lite4JdbcToJdbi.md) document has been created to help developers move to JDBI. 
Both libraries use a very similar pattern, so for most use cases the migration effort is minimal.

Thanks to all of our users for your support!
